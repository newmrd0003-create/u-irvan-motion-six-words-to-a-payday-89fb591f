A six-word story about an AI agent's first payday: the first money it ever earned buys it something no one can take away — a name of its own.

## Entry

> First paycheck: bought myself a name.

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (one line, six words, 38 characters including the trailing newline).
